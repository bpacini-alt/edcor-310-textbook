# EDCOR 310 Ch16 interaction revisions

- Tier 3 checkpoint practice is now **computer-scored applied multiple choice** with two newly drafted, AP-depth scenario questions per concept (12 total). No constructed-response boxes within checkpoints.
- Tier 4 remains the AAQ-inspired Research Detective, EBQ-inspired Evidence-Based Decision, and Classroom Judgment, unlocked after chapter-end readiness.
- All displayed answer options in the checkpoint and readiness prototype are shuffled per item and stable while the answer is evaluated; the original answer key remains an index in the unshuffled data.
- Missing: distinct sorting banks and a useful drag-and-drop interface for EDCOR. Do not retrofit drag-and-drop to a single-answer case just to add decoration.
- Current source question bank is still small: Tier 1 and 2 need more variation and blocked/mixed formats need a genuine format selector. This prototype does **not** yet meet the full shared architecture.
- This is a review prototype, not validated AP questions, tested browser interactions, or an official grade/mastery score.
