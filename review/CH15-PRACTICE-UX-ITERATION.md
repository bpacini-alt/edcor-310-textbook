# Chapter 15 practice pilot — UX and review notes

**Status:** Review-only. The preview is a standalone page and is not linked from the live chapter.

## What the preview tests

- End-of-concept panels remain collapsed so practice does not interrupt reading.
- Each concept uses a short blocked sequence: Tier 1 distinction → Tier 2 application → Tier 3 transfer.
- The chapter-end sequence interleaves concepts and adds an explicit understanding confirmation after correct answers.
- Five correct-and-understood answers reveal short constructed-response tasks.
- Advanced responses use criterion-by-criterion self-comparison rather than automatic writing scores.
- Answer options are shuffled per item but remain stable while the item is being evaluated.

## Why this first pass is intentionally narrow

The first pass uses the existing single-choice response pattern for all computer-scored items. It does not force Memory Match, Sorting, Quick Practice, phrase tiles, or a new Ed Psych-specific interaction into the chapter before we know whether the content progression works.

## Review checklist

- Test every concept checkpoint from a narrow mobile viewport and keyboard navigation.
- Confirm that each distractor represents a real misconception rather than a silly answer.
- Check that Tier 1, Tier 2, and Tier 3 differ in reasoning demand, not only sentence length.
- Check that the mixed readiness sequence really requires students to switch among concepts.
- Check the five-point advanced rubrics against the chapter's actual claims and evidence limits.
- Verify the hypothetical research numbers and all chapter claims before any publication-facing integration.
- Confirm that the page never implies that five correct answers establish mastery.

## Not yet included

- Persistent progress, student accounts, analytics, adaptive scheduling, or a mastery algorithm.
- Cross-chapter spiral review.
- Automatic scoring of written answers.
- A production JSON item bank in the shared practice-engines repository.
- Live Chapter 15 integration.
