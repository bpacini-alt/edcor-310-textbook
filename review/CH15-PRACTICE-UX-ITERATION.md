# Chapter 15 practice UX iteration

**Status:** review-only companion to the Chapter 15 pilot. No production chapter or shared assessment bank is changed.

## Design question

Can we preserve the strong end-of-concept checkpoint while giving EDCOR students the Econ-like control they already understand?

This iteration tests four ideas:

1. **Checkpoint first:** concepts remain collapsed, so the chapter still has a clear conceptual spine.
2. **Tier choice:** students select Foundations, Apply, or AP-style reasoning.
3. **Format choice:** students select **Mix it up** or a named activity type that is available for the chosen tier.
4. **Separate test-out:** the chapter-end section mixes the current chapter's concepts and uses the correct-plus-explain gate before showing advanced reasoning.

## What is intentionally borrowed from Econ

- tier buttons with a short description of the cognitive work;
- suggested activity counts of 10 / 5 / 3;
- a practice-type selector with **Mix it up**;
- compact repetitions with feedback;
- an interleaved chapter-end readiness check;
- an unlock after five correct responses plus an explicit understanding confirmation.

## What is intentionally not borrowed

- Econ-specific calculations, graphs, or market stories;
- a claim that practice counts certify mastery;
- an assumption that all existing Econ renderers fit every Ed Psych objective;
- automatic scoring of the advanced prompts;
- a live connection to earlier EDCOR chapter banks.

## Activity map for this pilot

| Selected tier | Formats shown |
| --- | --- |
| Foundations | Question & response; Memory Match |
| Apply | Question & response; Definition Detective; Sorting; Quick Practice |
| AP-style | Question & response; Sentence Construction |

The menu is deliberately small. It gives students choice without presenting a long list of formats before we know which ones support Ed Psych reasoning.

## Review checklist

### Navigation

- [ ] All six concepts are visible as collapsed checkpoints.
- [ ] Opening one checkpoint does not make the page feel like a long undifferentiated worksheet.
- [ ] The tier selection is visually distinct from the activity-type selection.
- [ ] Switching tiers preserves the concept and does not imply that a student has failed a previous tier.

### Practice behavior

- [ ] **Mix it up** rotates through formats at the selected tier.
- [ ] Choosing a named type produces repeated practice in that format.
- [ ] The 10 / 5 / 3 counts read as suggestions, not requirements.
- [ ] Feedback explains the reasoning rather than merely marking right or wrong.
- [ ] Board/round-based formats leave feedback visible before the student starts a new round.

### Chapter-end test-out

- [ ] The test-out reads as an optional synthesis, not as another concept checkpoint.
- [ ] Chapter 15 is selected and earlier banks are clearly unavailable rather than silently omitted.
- [ ] The five-correct-and-understood rule is understandable.
- [ ] The unlock language avoids claiming a formal mastery certification.
- [ ] The advanced prompts require judgment, evidence, and transfer.

## Decisions this pilot should inform

- whether named formats are worth keeping alongside **Mix it up**;
- whether the three-tier language is clear enough for Ed Psych;
- whether Tier 2 needs more classification work or more scenario-based choice;
- whether Sentence Construction is a useful bridge into self-reviewed constructed response;
- how much earlier-chapter spiral review should be added once those banks exist;
- which activity shells, if any, deserve a production-quality Ed Psych renderer.

## Out of scope for this pass

No new question types, no live content integration, no shared-bank migration, no analytics instrumentation, and no Chapter 16 build.
